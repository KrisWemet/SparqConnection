# UX — Today Flow

## Order (fixed)
Identity → Center‑Me → Daily Question → Micro‑Action → Journal → Appreciation → Reflection

## Cards

### 1) Identity
- Shows selected identity chip (e.g., "Patient Listener").
- Toggle "private today" (default visible).
- CTA: "Choose a new identity" (premium for custom names).

### 2) Center‑Me
- 20–40s grounding: breath (4–6), 1–2 lines of intent.
- If skipped 3× this week: suggest a shorter variant.

### 3) Daily Question (DQ)
- One concise prompt; Partner Notes thread for replies.
- Optional "Swap" (pull same‑tag alternative 1/day).
- CTA: "Save for Later" (bookmarks).

### 4) Micro‑Action
- 1 practical act (≤ 2 minutes) tuned to Love Languages.
- CTA: Mark done; variant if avoidant (more autonomy wording).

### 5) Journal (E2EE)
- Private by default; partner-visible toggle exists but warns.
- Audio notes optional later; never push content.

### 6) Appreciation
- Templates tuned to LL; channel choice (text/voice/in-person).
- CTA: Send/Copy; Partner Notes can acknowledge receipt.

### 7) Evening Reflection
- One question: "What shifted today?"; optional emoji scale.

## States
- Empty/incomplete: friendly nudge; no shame.
- Offline: cache last plan; queue writes; sync when online.
- Premium gates: clearly labeled; show benefits.

## Analytics (event names)
- `today_opened`, `identity_selected`, `center_completed`
- `dq_viewed`, `dq_swapped`, `dq_replied`
- `micro_marked_done`, `journal_saved`, `appreciation_sent`
- `reflection_logged`, `plan_completed`

## Accessibility
- Focus order logical; large tap areas; dyslexia-friendly copy.
- VoiceOver labels; contrast AA+; motion-reduced mode.

## Play (separate page)
- Async rounds; partner notified after each move (no spoilers).
- Low-cost entries to entice reluctant partners.
