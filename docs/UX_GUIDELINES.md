# UX Guidelines

## Palette (tokens)
- Background: `#FFFDF8` (ivory), `#F8FAFC` (mist)
- Primary CTA: `#FF6B6B` coral (hover #FF8A8A)
- Success: `#16A34A` green
- Info: `#6366F1` indigo
- Warning: `#F59E0B` amber
- Border: `#E5E7EB` gray-200/300
- Text: `#111827` gray-900

## Typography
- Base font-size 16px, line-height ≥ 1.5.
- Headings with clear size steps: 14/16/20/24.

## Components
- Button: 10–12px radius, visible focus ring, 44×44 min, disabled: 65% opacity with border.
- Card: lg radius (16–20px), thin border, subtle shadow.
- Stepper: thin rounded bars, success green fill, clear label.

## Copy Tone
- Short, kind, direct; no jargon.
- “Why this matters” is 1–2 lines; optional.
- Encouragement over evaluation; no shame.

## Accessibility
- AA contrast, visible keyboard focus, respect reduced‑motion.
- Large tap targets; generous spacing.
