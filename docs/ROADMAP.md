# Sparq Roadmap

## Vision
A warm, 5–8 minute daily ritual that helps couples build trust, understanding, and tiny moments of care — grounded in ethical behavioral science, not jargon or pressure.

## Guiding Principles
- Tiny steps, clear wins, repeatable rhythm.
- Plain language, no therapy jargon; short, kind copy.
- Opt‑in, transparent, and respectful of autonomy.
- Accessibility first (AA), mobile‑friendly, low friction.
- Measure what matters: completion, relevance, confusion, return rate.

## What’s Done
- First‑run onboarding with clear preferences and SSR guards.
- Today ritual (7 steps) with warm labels and “Why this matters”.
- “Say what you noticed” replaces jargon; channel choices.
- Bottom nav (mobile), Today stepper + progress, deep link to “Say it”.
- If–Then Builder (implementation intentions) on Today.
- Home hero with greeting, encouragement, identity, invite, and progress ring.
- First‑time coach marks on Home/Today.
- Server copy updates; plain‑language mapping + notifications copy.

## Doing Now
- Reflection recall of If–Then with “Did it help?” (wired).
- Bottom nav in (app) layout for consistency (done).
- Warm palette tokens + shared Button component (next).

## Next Up (1–2 sprints)
- Collapse completed cards with ✓ + Edit, keep flow airy.
- Progress persistence + server event logging per step.
- Quick Actions polish (deep link into step; prefilled states where safe).
- Coach marks spotlight + focus trap; improved positioning.
- Settings screen for preferences (time, tone, appreciation channel).
- Relevance loop: lightweight thumbs on Question relevance, micro‑actions.

## Longer Term
- Partner sync: gentle prompts for paired users, async alignment moments.
- “Moments” feed: small wins, notes, appreciations — private by default.
- Guided weeks: optional themes with short arcs (e.g., “Appreciation Week”).
- Experiments: brief monthly pulse; improved personalization from answers.

## KPIs
- Day‑1 completion ≥ 70%, Day‑2 ≥ 50%.
- Help‑open rates < 10% per card (clarity).
- Question relevance swaps ≤ 25%.
- “Say it” sent ≥ 60% on Day‑1.
- Weekly return rate ↑; time‑in‑flow ~5–8 min.
